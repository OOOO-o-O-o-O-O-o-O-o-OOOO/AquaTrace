AquaTrace bundled sample imagery

These locally bundled SVG scene illustrations are for inspecting the AquaTrace interface only. They are explicitly illustrative sample imagery, not scientific satellite scenes, measured products, or analysis results. The gallery files are separate from the public satellite basemap, which is provided by Esri.

Raw sample paths and MNDWI render sample paths are declared in src/data/scenes.ts. SceneProvider in that module is the small data-provider boundary intended for future local directory providers. No directory access or processing is performed by this application.
