# AquaTrace source

This is a standalone copy of the React + Vite app. It includes the current UI,
provider abstraction, example metadata, and bundled SVG samples.

From this directory, run `npm install` and then `npm run dev` to work on the
source, or run `npm run build` to create a fresh `dist/` bundle. For the
prebuilt local app, use the parent package's `python3 run_aquatrace.py`
command instead.
